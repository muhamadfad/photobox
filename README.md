# photobox

Aesthetic Korea & Y2K Online Photobooth Web Application built with React, Vite, Tailwind CSS, and Ant Design inspired clean styling.

## Fitur Utama

- **35 Template Photobooth Realistis:** Theater Ticket, Denim 1989, Roblox XXL, Polaroid Mosaic, Spotify Cassette, Vintage Mahogany, Purikura, Haru Cloud, dll.
- **Kamera Booth Interaktif:** Live webcam, burst auto multi-shot, single shot, dan fitur 1 kali foto otomatis mengisi semua slot frame.
- **Efek & Filter Estetik Kamera HP:** Grain analog, date stamp retro, halftone b&w, warm vintage, cyber pop, dll.
- **Dekorasi Stiker:** Beragam stiker lucu dan autentik (bintang, pita, hati, doodles).
- **Kustomisasi Teks:** Edit nama photostrip, tanggal, barcode, dan detail frame sesuai keinginan.
- **Export Ultra-HD (300 DPI):** Simpan foto dalam format PNG/JPEG kualitas tinggi tanpa kehilangan foto atau terdistorsi di HP.
- **Cetak Langsung:** Cetak photostrip langsung dengan layout bersih siap cetak ke kertas foto.

## Cara Menjalankan

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk produksi
npm run build
```
